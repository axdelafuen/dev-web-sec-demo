Identification and Authentication Failures

Vulnerable Version

  • No rate limiting (brute force attacks possible)
  • Detailed error messages (username enumeration)
  • No account lockout mechanism
  • Weak password policy (accepts "123")
  • Exposed detailed logs

Secure Version

  • Rate limiting (5 attempts / 5 min per IP)
  • Account lockout (15 min after 5 failures)
  • Generic error messages (no enumeration)
  • Strong password policy (8+ chars, complexity)
  • Secure anonymized logging

About A07:2021 - Identification and Authentication Failures

Authentication failures can allow attackers to compromise passwords, keys, session tokens, or exploit implementation flaws to assume other users' identities.

OWASP Recommendations:

  1. Implement multi-factor authentication (MFA)
  2. Never deploy with default credentials
  3. Validate password strength
  4. Limit failed authentication attempts
  5. Use secure session management
  6. Log and monitor suspicious attempts
